## ✨ 特性

- 🚀 **全新版本** — 基于谷歌扩展 MV3 规范开发，适用于 Chrome 浏览器新版本
- 🧱 **现代技术栈** — 采用 `Vue3 + WXT + TypeScript` 构建
- 🔓 **完全开源** — 可自行编译打包，也可直接下载现成的 zip 安装
- 🧦 **SOCKS5 带认证支持** — 配合同作者的 **HiLocalProxy** 小工具，完美解决主流浏览器不支持 SOCKS5 用户名密码验证的问题

## 📥 安装

### 方式一：Chrome 商店（推荐国际用户）

> 直达 Chrome Web Store 安装：<https://chromewebstore.google.com/detail/hiproxy/ammmjkfjeahfkfffncemmbpfdboclfah>

### 方式二：本地导入 zip 包

1. 从 [Releases](https://github.com/hicode0101/HiProxy/releases) 下载 `HiProxy-3.2.10-chrome.zip`
2. 打开 Chrome 扩展管理页：`chrome://extensions/`
3. 开启右上角的 **开发者模式**
4. 将 zip 文件 **直接拖入** 页面即可，无需解压
